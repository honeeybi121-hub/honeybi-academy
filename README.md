# Honeybi Academy — Oficial v1

Primeiro código-base oficial da Honeybi Academy, pronto para GitHub + Vercel.

## Rotas
- /
- /login
- /cadastro
- /dashboard
- /formacao
- /aula
- /certificado

## Rodar localmente
```bash
npm install
npm run dev
```

## Publicar na Vercel
Suba todo o conteúdo desta pasta na raiz do repositório `honeybi-academy`.
Depois importe o repositório na Vercel. O framework deverá ser detectado como Next.js.
